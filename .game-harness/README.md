# Dream of One Game Harness State

This directory records the active game-development harness state for Codex-led work.

It is not the issue tracker:
- Linear remains the source of truth for external work.
- Beads remains the internal execution graph.

It is the game-development memory layer:
- what the game is
- what stage is active
- what role reviews found
- what evidence exists
- where drift is happening
- how the next agent should continue

## Files

| File | Purpose |
|---|---|
| `game-seed.md` | Stable product promise and authority boundaries |
| `current-stage.md` | Current stage gate and deliverables |
| `tasks.md` | Harness-level task checklist, not issue SoT |
| `review-log.md` | Role review findings and decisions |
| `verification-ledger.md` | Command, visual, runtime, and playtest evidence |
| `drift-log.md` | Seed/stage drift and resolution |
| `continue-here.md` | Compact restart note for the next Codex session |
| `director-state.md` | Active director-level state and blockers |
| `milestones/` | Current and future milestone contracts |
| `contracts/` | Codex intake and evidence contracts |
| `council/` | Required council review definitions |
| `prompts/` | Reusable director prompts |
