# Director Tick Prompt

Use this prompt shape for a high-impact direction decision.

```text
Read first:
- AGENTS.md
- docs/direction/README.md
- .game-harness/director-state.md
- .game-harness/milestones/M1-protocol-proof.md
- .game-harness/contracts/evidence-contract.md

Decision needed:
[state the decision]

Evaluate:
- which pillar this strengthens
- which anti-game it risks
- what evidence would prove it
- whether it belongs to current milestone
- whether council review is required

Output:
- recommendation
- rejected alternatives
- required evidence
- stop conditions
- director decision ledger entry draft
```
