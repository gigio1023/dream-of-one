# Vertical Slice Plan

## Purpose

The vertical slice is the funding and recruitment proof. It must show that the team can ship the product thesis, not just describe it.

Target length: 10-30 minutes.

## Slice Name

`Station Soft Inquest`

## Slice Promise

The player performs one civic loop while Codex CLI-backed NPC society generates pressure and deterministic Station rules convert mistakes into Evidence.

## Required Player Path

| Beat | Location | Proof |
|---|---|---|
| 1 | Station | Read intake rule; learn that procedure speech matters. |
| 2 | Store | Codex-driven clerk pressures queue/label speech; backend validates outcome. |
| 3 | Studio | Codex-driven PM pressures source/owner/reason; artifact is created or defused. |
| 4 | Park | Codex-driven witness pressures public-flow behavior; dream speech becomes Statement. |
| 5 | Station | Officer compares prior records through deterministic intake/Inquest. |
| 6 | Verdict edge | Final why-line shows trigger, witness, record, stage, and outcome. |

## Must-Ship Features

| Feature | Slice Scope |
|---|---|
| Godot 3D loop | One connected civic hub with readable routes and text surfaces. |
| Korean-first UI | Korean default, English selectable. |
| Bounded speech acts | `SA_COMPLY`, `SA_INQUIRE`, `SA_FRAME`, `SA_BREAK`. |
| Codex CLI pressure worker | At least four NPC roles use Codex CLI to propose context-aware Korean lines. |
| Backend validation | Codex proposals cannot own deterministic state. |
| Evidence feed | Every state change has a why-line. |
| Station end state | Defuse/warning/verdict-ready outcomes. |
| Visual polish | Lighting, prop clusters, route cues, readable text, screenshots. |

## Stretch Features

| Feature | Add Only If Core Works |
|---|---|
| NPC walking routines | Use only if pressure readability is already clear. |
| Voice or TTS | Defer until Korean text voice is proven. |
| More NPC archetypes | Add Manager, QA, Caretaker, Investigator after four core roles work. |
| Procedural scenario variants | Add after deterministic Evidence replay is reliable. |

## Slice Acceptance Tests

| Test | Pass |
|---|---|
| Clean cover | Player can comply through the loop and avoid verdict-ready. |
| Messy repair | Player can create artifacts, repair at Station, and receive warning. |
| Lucid fracture | Player can use dream/non-procedural speech and reach verdict-ready. |
| Codex rejection | Invalid Codex proposal is rejected and fallback line appears. |
| Blind comprehension | Tester can explain why Exposure changed without reading docs. |
| Capture evidence | Opening and verdict screenshots prove readable UI and text. |

## Demo Video Structure

1. 5 seconds: Station exterior, Korean HUD, first rule.
2. 20 seconds: Store Codex-driven pressure and bounded speech.
3. 20 seconds: Studio artifact creation.
4. 20 seconds: Park public-flow failure.
5. 30 seconds: Station intake compares records.
6. 15 seconds: verdict-ready why-line.

The video should sell the hook in under two minutes.
