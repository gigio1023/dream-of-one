# Team And Production Plan

## Team Strategy

Build a small team around the actual risk: Codex CLI-powered social pressure with deterministic game authority.

Do not build a large content team before the vertical slice proves the loop.

## Core Team For Vertical Slice

| Role | Responsibility | Why Needed |
|---|---|---|
| Game Director / Product Owner | Own hook, scope, pitch, milestone calls, and final tradeoffs. | Prevents AI feature sprawl and unclear genre identity. |
| Godot Gameplay Engineer | Player control, interaction zones, UI, scene state, tool scripts, captures. | Proves the game is playable, not only backend logic. |
| Backend / Codex Systems Engineer | ObservationFrame, proposal schema, Codex CLI worker adapter, validation, Evidence. | Owns the core Codex + deterministic authority split. |
| Narrative Designer / Korean Writer | Cover Tests, Korean-first barks, Station prompts, why-lines, playtest wording. | The game lives or dies on text pressure quality. |
| 3D Environment / Technical Artist | Free asset curation, lighting, layout, prop clusters, readability. | Makes the slice look authored with limited assets. |
| Producer / QA Coordinator | Milestones, build hygiene, playtest schedule, bug triage, pitch assets. | Makes the team fundable and predictable. |

## Part-Time / Contract Needs

| Role | When | Output |
|---|---|---|
| Sound Designer | After text loop works. | Procedural audio motifs, Station pressure stings, ambience. |
| UI/UX Designer | During vertical slice. | HUD readability, speech-act presentation, evidence feed. |
| Localization Editor | Before public demo. | English pass preserving Korean source tone. |
| Marketing / Trailer Editor | Funding gate. | Two-minute pitch video and capsule assets. |
| QA Playtesters | Every milestone. | Blind comprehension reports and regression lists. |

## Hiring Order

1. Backend / Codex Systems Engineer.
2. Godot Gameplay Engineer.
3. Narrative Designer / Korean Writer.
4. 3D Environment / Technical Artist.
5. Producer / QA Coordinator.
6. Audio, UI, localization, marketing contractors.

## Milestones

| Milestone | Duration Target | Output |
|---|---:|---|
| M0 Scope Lock | 2 weeks | Final slice spec, AI proposal schema, team budget model. |
| M1 Playable Skeleton | 4 weeks | Godot hub, four zones, HUD, speech acts, deterministic local loop. |
| M2 Codex Pressure Prototype | 4 weeks | Codex CLI proposals, schema validation, fallback, Evidence. |
| M3 Authored Scenario Pass | 4 weeks | Korean line bank in-game, location dressing, Station arc. |
| M4 Vertical Slice Polish | 4-6 weeks | Visual/audio pass, playtest fixes, screenshots, pitch video. |
| M5 Funding Package | 2 weeks | Deck, build, budget, roadmap, risk register, outreach list. |

## Full Launch Team Shape

If vertical slice succeeds, expand to:

- 2 Godot engineers;
- 1 backend/Codex engineer;
- 1 narrative lead plus contract line editor;
- 1 environment/technical artist plus asset contractor;
- 1 UI/audio contractor pool;
- 1 producer/marketing owner;
- external QA near milestones.

## Production Rule

Every role must be able to point to the same playable proof:

> Codex CLI makes NPC pressure feel alive, deterministic rules make the outcome fair, and the player can understand the Evidence trail.
