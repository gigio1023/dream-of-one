# Simulator Benchmarks

This directory contains source-backed benchmark research for using simulator
game design as Dream of One's practical design scaffold.

Research here is not product truth by itself. Stable conclusions must be
reflected into active direction, scenario, runtime, or harness documents before
implementation work uses them as authority.

## Operating Rule

Dream of One should not start from "LLM conversation game" as the genre.

It should first prove a small, readable simulator:

```text
ordinary procedure
-> player response
-> comparison against local expectation
-> visible social consequence
-> formal record
-> Station reconciliation
```

Only after that baseline is legible should dream law, LLM wording, and broader
social simulation be layered on top.
