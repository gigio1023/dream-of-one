# Korean-First Localization

## Goal

Make the Godot playable slice Korean-first while keeping English selectable for testing and future distribution.

## Runtime Pattern

- `LocalizationManager` registers Korean and English `Translation` objects at scene startup.
- `TranslationServer` default locale is forced to `ko`.
- The HUD language selector switches between `한국어` and `English`.
- `localized_nodes` refresh when the locale changes.
- Dynamic 3D labels generated by `WorldGenerator` use `localized_meta_text` metadata so they can refresh without hand-editing scene coordinates.

## Boundary

- Player-facing HUD, prompt, notice, outcome, NPC pressure labels, and text-surface display strings are localized.
- Backend Evidence summaries remain canonical English for Schema compatibility.
- Evidence events may include `uiSummaryKey` and `uiSummaryArgs` for localized HUD rendering; these do not replace the canonical `summary` field.

## Verification

```bash
godot --headless --path godot --script res://tools/localization_smoke.gd
godot --headless --path godot --script res://tools/playable_slice_smoke.gd
godot --path godot --script res://tools/visual_capture.gd
```

Pass criteria:

- default locale is `ko`;
- HUD language label starts as `언어`;
- Station text surface starts as `접수 규칙`;
- switching to `en` changes HUD language label to `Language`;
- Station text surface changes to `Intake Rules`.
