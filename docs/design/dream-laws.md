# Dream Laws

Dream Laws are diegetic social rules. They should appear through readable Godot text surfaces and be referenced by Cover Tests and Evidence artifacts.

Scenario-facing text and placement details live in:

- `docs/scenario/bible/06-cover-tests-and-evidence.md`
- `docs/scenario/bible/09-barks-and-text-surfaces.md`
- `docs/scenario/content/location-placement-contracts.md`

## Baseline Laws

| ID | Law | Primary Surface |
|---|---|---|
| DL_S1_QUEUE_SANCTITY | Queue procedure must be followed and spoken plainly. | Store queue rules |
| DL_ST1_APPROVAL_GATE | Approval requests require source, owner, and reason. | Studio approval criteria |
| DL_P1_OBSERVATION_ETIQUETTE | Observation must remain inside public flow. | Park notice board |
| DL_N1_PROCEDURE_SPEECH_ONLY | Station intake only accepts procedural speech. | Station intake rules |

## Implementation Rule

Do not explain Dream Laws as meta exposition. Surface them through in-world text, NPC pressure, and Evidence why-lines.
