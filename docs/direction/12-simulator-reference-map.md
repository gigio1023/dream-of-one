# Simulator Reference Games Map

Status: active reference map
Date: 2026-05-14
Source: `docs/research/simulator-benchmarks/2026-05-14/`

References are not genre assignments. This map captures what Dream of One should
borrow as playable grammar and what it must not copy.

## Shared Patterns

- Procedure first, fiction second.
- Judgment cues are the board: signs, receipts, reports, transcripts,
  records, and Station citations.
- Pressure needs a record that can travel, not only a meter.
- Normality must be taught before deviation can be fair.
- Watchers should be local and partial.
- Repair should be useful but never erase the original record.
- LLM output should render wording after backend state is locked.

## Contradictions To Preserve

- Dream of One borrows authority-game procedure while keeping authority outside
  the player.
- It borrows detective-game evidence UI while rejecting the player-as-detective
  fantasy.
- It borrows life-sim recurrence while rejecting broad life-management scope.
- It borrows LLM social texture while rejecting open-ended chatbot authority.

## Hard Noes

- no surveillance dashboard as the main player verb;
- no case board, clue hunt, culprit objective, or official investigator role;
- no broad economy, farm, household, or town management before Same Order proof;
- no combat/disguise/inventory stealth pivot;
- no provider-owned suspicion, Evidence, report, inquest, verdict, or session
  termination;
- no public Codex/OpenAI/LLM marketing claim before provider/fallback parity is
  proven in the build.

## Gate

Required gate: `GS-TASTE-CLARITY` plus M1 simulator adoption proof.

Pass condition:

- Fresh player can explain the normal Store procedure.
- Fresh player can explain which line damaged or preserved cover.
- Store record is visible before Station uses it.
- Station cites the exact Store record.
- Provider-off fallback proves the same outcomes.
- Clean, repair, soft report, and inquest routes remain deterministic.
