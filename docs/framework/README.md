# Framework Guidance

This directory contains project-local Game Studio review and proof guidance for Dream of One.

| File | Use |
|---|---|
| `evidence-gates.md` | Define internal artifact gates for playable proof, captures, test output, playtest notes, and release-claim checks. |
| `substantive-review.md` | Shape Codex-led role reviews that judge game substance instead of template completion. |

Current project routing and stage are recorded in `.game-studio/project-state.md`. Current M1 execution state remains in `.game-harness/`.
