# Godot Migration

This directory is the project-scoped source of truth for the Dream of One Godot Runtime Path migration.

Migration guidance does not live in `godot-best-practice` or any other reusable agent skill. Agent skills may provide generic Godot workflow rules, but Dream of One authority, Schema, Evidence, Linear issue, and cutover decisions belong here.

## Documents

- `overlay.md`: active migration overlay and authority map.
- `target-godot-architecture.md`: Godot runtime architecture and determinism boundary.
- `schema-and-action-specification.md`: ObservationFrame and NpcCommandEnvelope project Schema details.
- `validation-gates.md`: required verification gates and artifacts.
- `linear-issue-breakdown.md`: executor-ready issue plan.
- `parity-matrix.md`: runtime parity status.
- `evidence-cutover.md`: Evidence artifact ownership and cutover requirements.
- `inventory.md`: migrated runtime inventory.
- `playable-rebuild/`: playable 3D social-stealth rebuild architecture, scenario, execution plan, and validation gates.
