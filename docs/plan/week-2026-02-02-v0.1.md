# Week Plan - Prototype v0.1 (2026-02-02)

## Objectives
- Deliver the MCSS playable slice defined in project.md.
- Prove the deterministic Dream Law + Cover Test loop end-to-end.
- Surface clear Suspicion/Exposure reasons in UI and logs.
- Keep Diagnostics clean and PlayMode tests passing.

- Systems: DreamLaw runtime + detectors, Suspicion/Exposure, CoverTest runtime, Inquest Dossier verdict.
