# Dream of One Director Application

## Director-Level Thesis

Dream of One should be led as:

> A Korean-first 3D social-surveillance game where the player is not investigating a mystery; the Station investigates the player's text, turns speech into Evidence, and closes the session through deterministic Dream Law.

## Strategic Risks

| Risk | Why It Matters | Director Response |
|---|---|---|
| Player becomes investigator | Makes a different genre | Reject clues/tools/framing that make player the authority |
| AI becomes rule owner | Breaks deterministic product law | Codex proposes text only; backend/runtime decides |
| 3D becomes decoration | Wastes effort and still feels like a test scene | Require spatial pressure/contact-sheet proof |
| Text becomes lore | Weakens core interaction | Every important text surface needs risk/consequence |
| Store promise overreaches | Public expectation breaks trust | Publish only build-truth claims |

## Milestone Roadmap

### M0: Thesis Lock

Goal:
- Lock what this game is and is not.

Evidence:
- thesis
- creative pillars
- anti-pillars
- red-line list

Exit:
- new work can be rejected using the thesis.

### M1: Protocol Proof

Goal:
- Prove text -> Evidence -> Exposure -> consequence.

Evidence:
- backend fixture
- Godot surface
- one successful and one risky response
- why-line output

Exit:
- Codex text proposal cannot alter verdict authority.

### M2: Social Pressure Prototype

Goal:
- Make NPC/Station investigation readable in play.

Evidence:
- Station intake/probe/escalation playable path
- screenshot or video
- player action timeline
- first playtest notes

Exit:
- player understands they are being investigated.

### M3: 3D Value Gate

Goal:
- Justify 3D over cheaper presentation.

Evidence:
- player view and Station/system view contact sheet
- route and sightline review
- text readability at gameplay distance
- keyboard-only path

Exit:
- 3D space increases surveillance pressure, not just production cost.

### M4: Vertical Slice

Goal:
- One near-final 15-30 minute loop.

Evidence:
- intake -> Cover Test -> Exposure -> inquest/verdict arc
- art/audio/UI target
- localization proof
- QA checks
- pitch/demo capture

Exit:
- team can estimate production from real cost.

### M5: Public Demo Candidate

Goal:
- Prepare a truthful demo.

Evidence:
- install/run guide
- Codex CLI requirement disclosure
- store/pitch copy
- screenshots from actual build
- known limitation list

Exit:
- public promise matches build truth.

## Director Council for Dream of One

Use these lanes for high-impact decisions:
- `Dream Law Counsel`: rule authority, thresholds, verdict.
- `Text Danger Reviewer`: whether text creates gameplay risk.
- `Station Pressure Reviewer`: whether player is being investigated.
- `Systems Producer`: scope, milestone, evidence completeness.
- `Godot Evidence Reviewer`: whether 3D/playable proof exists.
- `Taste Contrarian`: generic mystery/noir/SCP/lore drift.

Final reducer:
- Director decision record.
- No council lane directly changes product direction.

## Next Director-Level Task

The next strategic task is not "add more features." It is:

1. finalize thesis and pillars,
2. create director decision ledger,
3. define M1 Protocol Proof,
4. decide what evidence would justify continued 3D investment,
5. only then dispatch implementation work.
