## Use

This pack should inform the next Store/Station implementation pass:

- expose environment objects as action descriptors;
- feed the same descriptors to player UI, role agents, provider packets,
  validators, and evidence logs;
- keep provider output bounded to choosing/phrasing available actions;
- make every important social reaction readable through records, citations, and
  civic pressure;
- add economy only as one small playable loop at a time: source, pool, actor
  decision, sink/transform, player-readable consequence.
