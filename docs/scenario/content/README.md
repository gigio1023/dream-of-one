# Scenario Content

Use this directory for reusable scenario writing and placement source material.

| File | Use |
|---|---|
| [dialogue-line-bank.md](dialogue-line-bank.md) | NPC barks, overheard lines, interrogation lines, defuse source material, and current conversation choice sets. |
| [social-simulation-cards.md](social-simulation-cards.md) | Location procedures, NPC pressure cards, storylet template, Same Order design cell, and provider prompt context. |
| [environment-affordance-map.md](environment-affordance-map.md) | M1 Store/Station regression map: reuse validation and visibility patterns, not its M3R-retired Store layout or economy values. |
| [same-order-storylet-packet.md](same-order-storylet-packet.md) | M1 Store-to-Station regression packet; scripted adapter source, not M3R production policy. |
| [same-order-asset-bill-of-materials.md](same-order-asset-bill-of-materials.md) | v1 (3D) asset BOM — historical. Active asset policy: [`docs/art/asset-pipeline.md`](../../art/asset-pipeline.md). |
| [location-placement-contracts.md](location-placement-contracts.md) | Placement expectations for in-world text, routes, landmarks, sightlines, props, lighting, and audio motifs. |
| [korean-voice-notes.md](korean-voice-notes.md) | Korean-first tone notes and term variants. |

Player-facing authoring follows the active [core loop](../../game/core-loop.md),
[content guide](../../game/content-guide.md), and [NPC agent
loop](../../game/npc-agent-loop.md). The [conversation suspicion
prologue](../bible/12-conversation-suspicion-prologue.md) and Store packets are
source/regression material that must be adapted to M3R rather than copied.
v1 direction sources (design spine, benchmark briefs, prototype targets)
remain under [`docs/archive/v1-direction/`](../../archive/v1-direction/) for
history only.
