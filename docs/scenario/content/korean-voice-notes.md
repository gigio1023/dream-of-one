# Korean Voice Notes

Dream of One should sound like a public notice, intake desk, and case log colliding with dream logic. The voice is formal, plain, procedural, and quietly threatening.

## Korean Source Rules

| Rule | Application |
|---|---|
| Korean is source voice. | Write Korean first for scenario-facing text, then localize English intent. |
| Use formal-polite for authority. | Station notices, HUD objectives, verdicts, and system pressure use `하십시오체` or institutional passive forms. |
| Use softer politeness for low pressure. | Store and Park can use service/civic `해요체` until escalation. |
| Avoid direct pronouns. | Prefer omitted subjects or role nouns: `보고를 유지하세요`, `절차 질문에만 답하세요`. |
| Keep institutional language plain. | Use `필수`, `금지`, `예외`, `허용`, `기록`, `접수`, `판정`. |
| Keep surrealism in nouns. | `꿈의 법 위반 기록이 접수되었습니다` works better than poetic dream explanation. |

## Sample Lines

| Function | Korean | English Intent |
|---|---|---|
| Dream Law | `꿈의 법: 절차 질문에는 절차로만 답해야 합니다.` | Dream Law: procedural questions require procedural answers. |
| Cover Test | `커버 테스트: 보고 내용의 내부 일관성을 확인합니다.` | Cover Test: checks internal consistency of report content. |
| Exposure | `노출도 +25. 절차 불일치가 기록되었습니다.` | Exposure +25. Procedural mismatch recorded. |
| Station intake | `스테이션 접수가 열렸습니다. 보고 데스크에서 답변을 유지하세요.` | Station intake is open. Maintain answers at the report desk. |
| Inquest | `심문이 열렸습니다. 설명이 아니라 절차만 접수됩니다.` | Inquest is open. Procedure, not explanation, is accepted. |
| Verdict | `판정 준비 완료. 세션을 닫을 증거가 확보되었습니다.` | Verdict ready. Evidence is sufficient to close the session. |
| why-line | `마지막 why-line: 담당자가 절차 불일치 노트를 열었습니다.` | Last why-line: officer opened a procedural mismatch note. |
