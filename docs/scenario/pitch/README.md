## Core Correction

The current Godot slice is not yet an AI-powered game. It is an AI-ready prototype.

The pitchable product thesis is:

> Codex CLI proposes NPC social pressure, questions, reports, and local phrasing. Deterministic backend rules own validation, Exposure, Station intake, Inquest, verdict, session termination, fallback, and Evidence.

This split is the production advantage. It lets the game feel reactive without letting the Codex worker become the game master.

## Funding Readiness Standard

Do not pitch this as "an AI API wrapper." Pitch it as a small, authored social-stealth game with Codex CLI-driven NPC interaction and measurable vertical slice gates.

## External Pitch Baseline

Recent publisher guidance and industry pitch material repeatedly asks for:

- concise deck;
- clear hook;
- realistic team;
- budget and timeline;
- playable demo or vertical slice;
- proof that the team can finish.
