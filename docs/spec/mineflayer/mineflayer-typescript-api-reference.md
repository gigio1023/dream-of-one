## 2) `BotOptions` Reference

### 2.1 High-value options
| Option | Type | Runtime default | Notes |
|---|---|---|---|
| `host` | `string` | `localhost` | Server host |
| `port` | `number` | `25565` | Server port |
| `username` | `string` | `'Player'` | Offline username unless auth flow used |
| `auth` | `'mojang' \| 'microsoft' \| ...` | `'mojang'` docs default | For online account auth |
| `version` | `string \| false` | `false` | Auto version detect when false |
| `logErrors` | `boolean` | `true` | Loader logs bot `error` event when true |
| `hideErrors` | `boolean` | `false` | Runtime default differs from some docs text |
| `loadInternalPlugins` | `boolean` | `true` | Enables all internal plugins unless overridden |
| `plugins` | `Record<string, boolean \| Plugin>` | `{}` | Override/disable/load plugin functions |
| `client` | `Client` | `null` | Attach existing `minecraft-protocol` client |
| `brand` | `string` | `'vanilla'` | Client brand payload |
| `respawn` | `boolean` | `true` | Auto respawn when death event path occurs |
| `physicsEnabled` | `boolean` | enabled by default | Controlled in physics plugin |
| `chatLengthLimit` | `number` | feature-dependent | Split length for `bot.chat` |
| `defaultChatPatterns` | `boolean` | `true` | Auto whisper/chat patterns |

### 2.2 Settings-related options
These flow into `bot.settings` and `settings` packet behavior:
- `chat`
- `colorsEnabled`
- `viewDistance`
- `difficulty`
- `skinParts`
- `mainHand`
- `enableTextFiltering`
- `enableServerListing`

### 2.3 Option behavior for `plugins`
```ts
const bot = createBot({
  host: '127.0.0.1',
  username: 'typed',
  loadInternalPlugins: true,
  plugins: {
    chat: false,             // disable internal chat plugin
    myPlugin: (bot) => {},   // external plugin function
    physics: true            // explicit force-enable
  }
})
```

## 3) Lifecycle and Session Events

### 3.1 Lifecycle order (typical)
1. `connect`
2. `inject_allowed`
3. `login`
4. `spawn`
5. runtime loop events
6. `end` / `kicked`

### 3.2 Essential lifecycle handlers
```ts
bot.on('inject_allowed', () => {})
bot.on('login', () => {})
bot.on('spawn', () => {})
bot.on('respawn', () => {})
bot.on('kicked', (reason, loggedIn) => {})
bot.on('end', (reason) => {})
bot.on('error', (err) => {})
```

## 13) Known Drift Notes for TypeScript Users
- `title_times` and `title_clear` are runtime/docs events but absent in current `index.d.ts`.
- `unmatchedMessage` is present in `index.d.ts` but not emitted in current runtime source.
- `hideErrors` default differs between docs text and runtime default.
- Node baseline in package/CI is 22, while some docs text still references older baseline.

## 14) Recommended TypeScript Wrapper Pattern
```ts
export interface SafeBotContext {
  bot: Bot
  sessionId: string
  npcId: string
}

export async function safeSay(ctx: SafeBotContext, text: string): Promise<void> {
  const normalized = text.slice(0, 200)
  ctx.bot.chat(normalized)
}
```
